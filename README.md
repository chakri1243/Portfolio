# 🚀 Chakri Gutha Portfolio

A premium AI & Machine Learning portfolio built using React, Vite and Framer Motion.

## ✨ Features

- Premium Hero Section
- About Me
- Job Simulations
- Skills
- Currently Learning
- Projects Showcase
- GitHub Dashboard
- Resume Preview
- Contact Section
- Responsive Design
- Glassmorphism UI
- Command Palette
- Theme Switcher

## 🛠 Tech Stack

- React
- Vite
- JavaScript
- CSS
- Framer Motion
- React Icons

## 📦 Installation

```bash
npm install
npm run dev
```
